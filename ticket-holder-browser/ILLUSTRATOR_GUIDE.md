# Illustrator SVG 模板制作教程

## 准备工作

### 1. 创建新文档

1. 打开 Adobe Illustrator
2. 文件 → 新建（Ctrl/Cmd + N）
3. 设置参数：
   - **名称**: ticket-template
   - **宽度**: 1011 px
   - **高度**: 638 px
   - **单位**: 像素
   - **颜色模式**: RGB
   - **栅格效果**: 高分辨率 (300 PPI)
   - **对齐到像素网格**: 取消勾选

### 2. 设置参考线

1. 视图 → 标尺 → 显示标尺（Ctrl/Cmd + R）
2. 从标尺拖拽参考线到画布：
   - 上下左右各留 20px 安全边距
   - 水平中线: 319px (高度的一半)
   - 垂直中线: 505.5px (宽度的一半)

## 导出 SVG

### 方法 1: 保存为 SVG（推荐用于开发）

1. **文件 → 存储为** (Ctrl/Cmd + Shift + S)
2. **格式**: SVG (*.SVG)
3. **SVG 选项**:
   - SVG 配置文件: **SVG 1.1**
   - 字体 → 类型: **SVG** (保留文本可编辑性)
   - 字体 → 子集: **无**
   - 图像 → 位置: **嵌入**
   - 对象 ID: **图层名称**
   - 小数位数: **2**
   - ✅ 最小化
   - ✅ 响应式
   - ❌ 不勾选"将文本转换为轮廓"（保持文本可搜索替换）

### 方法 2: 导出为 SVG（用于最终发布）

1. **文件 → 导出 → 导出为** (Ctrl/Cmd + E)
2. **格式**: SVG
3. 点击"导出"后设置：
   - 样式: **内部 CSS**
   - 字体: **SVG**（开发阶段）或 **转换为轮廓**（发布阶段）
   - 图像: **嵌入**
   - ✅ 缩小
   - ✅ 响应式

## 占位符规则

### 命名规范
```
格式: {{fieldName}}
要求:
  - 使用双花括号
  - 驼峰命名法
  - 不含空格
  - 区分大小写
```

### 可用占位符列表

#### 基本信息
- `{{trainNumber}}` - 车次号
- `{{departureStation}}` - 发站
- `{{destinationStation}}` - 到站

#### 时间信息
- `{{travelDate}}` - 格式化日期（2024年11月01日）
- `{{travelDateRaw}}` - 原始日期（2024-11-01）
- `{{departureTime}}` - 发车时间（17:40）

#### 座位信息
- `{{seatLevel}}` - 席别（硬座/软座等）
- `{{carriage}}` - 车厢（05车）
- `{{seat}}` - 座位号（008号）
- `{{seatInfo}}` - 完整信息（硬座 05车008号）

#### 乘客信息
- `{{name}}` - 姓名
- `{{idNumber}}` - 证件号

#### 价格信息
- `{{fare}}` - 纯数字（2.00）
- `{{fareWithSymbol}}` - 带符号（¥ 2.00）

#### 其他信息
- `{{ticketNumber}}` - 票号
- `{{typeOfBusiness}}` - 业务类型
- `{{businessTag}}` - 业务标签（【退】）
- `{{eTicketNumber}}` - 电子票号

## 设计建议

### 颜色方案
```css
/* 主色系 */
主蓝色: #0066CC  /* 标题、边框 */
深蓝色: #004999  /* 深色元素 */
浅蓝色: #E3F2FD  /* 背景装饰 */

/* 强调色 */
红色: #D32F2F    /* 票价、重要信息 */
橙色: #FF9800    /* 票价框边框 */

/* 文字颜色 */
主文字: #000000  /* 重要信息 */
副文字: #333333  /* 常规信息 */
辅助文字: #666666 /* 标签 */
次要文字: #999999 /* 票号等 */

/* 背景色 */
白色: #FFFFFF    /* 主背景 */
米黄: #FFF3E0    /* 票价框背景 */
```

### 字体大小层级
```
特大号 (72pt): 车次号
大号 (56pt): 车站名、票价
中号 (36-42pt): 标题、日期时间、座位
常规 (28pt): 乘客信息
小号 (20pt): 票号、辅助信息
```

### 布局技巧

1. **网格系统**: 使用 Illustrator 的网格功能对齐元素
2. **图层管理**: 
   - 背景层
   - 装饰层
   - 文字层
   - 标记层（占位符）
3. **命名规范**: 给重要图层命名，便于后续修改

## 常见问题

**Q: 中文字体在其他系统显示不正确？**
A: 使用通用字体族，如 `font-family="Arial, Microsoft YaHei, sans-serif"`

**Q: 占位符没有被替换？**
A: 检查格式是否为 `{{fieldName}}`，确保文本未被转换为轮廓

**Q: 导出的 PNG 模糊？**
A: 确保 SVG 尺寸正确（1011×638px），Canvas 设置了正确的分辨率

**Q: 文本溢出边界？**
A: 为长文本预留足够空间，或在代码中添加文本截断逻辑
