# 车票图片生成功能

## 功能说明

新增了浏览器端生成车票图片的功能，可以将解析出的车票数据生成为 85.6mm × 54mm @ 300dpi (1011 × 638 像素) 的图片。

## 技术实现

- **纯浏览器端实现**：使用 Canvas API 生成图片，无需服务器
- **标准尺寸**：85.6mm × 54mm @ 300dpi，符合标准卡片尺寸
- **高清输出**：300dpi 分辨率，适合打印

## 使用方法

1. 上传 OFD 或 PDF 格式的电子发票文件
2. 点击"开始解析"按钮
3. 解析成功后，会自动生成车票图片预览
4. 点击"下载图片"按钮即可保存为 PNG 格式

## 图片包含信息

- 车次号（大号字体显示）
- 发站和到站（带箭头）
- 发车日期和时间
- 席别、车厢、座位号
- 票价（红色醒目显示）
- 乘客姓名和证件号
- 票号（右下角小字）
- 业务类型标注（如"退"、"改"等）
